# Endaxis 设计系统

本目录维护可复用控件、控件状态和共享视觉变量。功能页通过 `@/design-system` 导入公共组件，不直接引用组件内部文件。

公共控件负责按钮、输入、选择、表单、弹窗、抽屉与浮层的主题和基础交互；具体业务布局仍在功能组件中。操作、页签和选择卡片优先使用 `EaButton`，选中状态通过 `pressed` 表达。浮层表面使用 `EaTooltip`、`EaPopover` 或 `ea-floating-surface`，不要在业务 CSS 重复定义通用背景、边框与阴影。

布局间距优先使用 `--ea-space-1` 至 `--ea-space-6`。时间轴和动作图的坐标、轨道、节点与连线属于专用几何，不强制套用通用间距或按钮外观；其基础表面与文字仍需适配深浅主题。文件、颜色、范围输入以及必须保留中间草稿或立即聚焦行为的高频编辑器，允许保留原生控件，并验证键盘与焦点操作。

完整的界面约定和验收清单见 [界面开发](../../docs/development/ui.md)。公共组件 API 与结构守卫测试是最终依据。
