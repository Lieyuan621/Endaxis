# Endaxis 设计系统

本目录统一管理可复用控件、控件状态及共享视觉语言。

## 使用规范

- 统一从 `@/design-system` 导入公共组件，不要直接导入组件内部文件。
- 操作按钮使用 `EaButton`，可选择的筛选项使用 `EaFilterChip`。
- 破坏性删除操作的图标统一使用 `EaDeleteIcon`；字符 `×` 仅表达关闭或移除标签，
  不作为删除图标使用。
- 标签、提示、校验错误以及横向／纵向表单布局使用 `EaFormField`。
- 弹窗结构和关闭行为使用 `EaDialog` 与 `EaDialogActions`。
- 业务布局和时间轴专用视觉样式应保留在对应功能组件中。
- 对于已经由本目录负责的行为，不要在页面中新增 `.el-*`、`:deep(.el-*)` 或
  `:global(.el-*)` 覆盖。
- 需要新的通用控件表现时，优先为基础组件增加职责明确的属性或变体，不要新增只服务于
  单个页面的通用控件样式类。
- 当现有 `Ea*` 组件已经覆盖所需行为时，继续使用原生控件必须在这里记录例外原因。

当前允许的原生控件例外应保持在最小范围内：`CustomNumberInput` 负责允许中间输入状态的
数字草稿解析；`TimelineGrid` 的高频编辑器需要通过程序立即聚焦，因此继续使用原生控件；
文件、颜色和范围输入仍保留浏览器专用行为，当前基础组件暂不覆盖这些类型。

公共组件 API 和结构守卫测试是最终依据。本文件只说明设计系统的职责和使用边界，不作为
组件使用教程。
