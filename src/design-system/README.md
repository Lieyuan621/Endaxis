# Endaxis 设计系统

本目录统一管理可复用控件、控件状态及共享视觉语言。

## 使用规范

- 统一从 `@/design-system` 导入公共组件，不要直接导入组件内部文件。
- 操作按钮使用 `EaButton`，可选择的筛选项使用 `EaFilterChip`。
- 工作台两侧活动栏统一使用 `EaActivityRailButton`；通过 `side` 指定指示条所在内侧，
  仅在图像留白造成视觉尺寸不一致时使用 `iconSize` 做光学修正。
- 破坏性删除操作的图标统一使用 `EaDeleteIcon`；字符 `×` 仅表达关闭或移除标签，
  不作为删除图标使用。
- 通用布局间距优先使用 `--ea-space-1` 至 `--ea-space-6` 的 4px 基准尺度；
  时间轴坐标和图形尺寸等业务几何值不受此约束。
- 强调色或危险色填充上的高对比文字与图标使用 `--ea-on-accent`、`--ea-on-danger`，
  不要在通用控件中直接写黑色或白色。
- 标签、提示、校验错误以及横向／纵向表单布局使用 `EaFormField`。
- 弹窗结构和关闭行为使用 `EaDialog` 与 `EaDialogActions`。
- 自定义弹窗、抽屉和浮层的关闭操作统一使用 `EaCloseButton`；`size` 只表达点击区域尺寸，
  默认透明背景，并且只在支持精细指针悬停的设备上改变图标颜色。
- 移动端弹窗的视口宽高、外层滚动和头尾固定由 `EaDialog` 统一负责；功能组件只定义
  内容区特有的内边距、满高或内部滚动方式。
- 移动端底部抽屉使用 `EaDrawer`；底部方向、页面根部挂载、滚动锁定和内容区表面由基础
  组件统一负责，功能组件仅保留自身高度与确有差异的关闭行为。
- `EaSelect` 的 `size` 同时控制输入区和传送到页面根部的选项列表；`popperClass` 仅用于
  命中特效编辑器等确有独立视觉语义的功能弹出层。
- 提示与点击浮层统一使用 `EaTooltip`、`EaPopover`；两者会自动附加共享表面、箭头和
  主题样式。自定义 `popperClass` 只负责内容宽度、内边距或语义强调色，不再重复定义
  通用背景、边框、阴影和圆角。
- 非 Element Plus 实现的右键菜单等浮层使用 `ea-floating-surface`，并通过浮层变量表达
  必要的业务变体；上下文菜单层级统一使用 `--ea-z-context-menu`。
- 普通操作、页签和选择卡片优先使用 `EaButton` 并通过 `pressed` 暴露选择状态；必须保留
  独立拖拽表面的卡片使用 `role="button"`、键盘事件及对应的 ARIA 状态。
- 业务组件的纯悬停反馈统一放入 `@media (hover: hover) and (pointer: fine)`；键盘焦点反馈
  使用独立的 `:focus-visible`，不能依赖悬停样式。
- 业务布局和时间轴专用视觉样式应保留在对应功能组件中。
- 对于已经由本目录负责的行为，不要在页面中新增 `.el-*`、`:deep(.el-*)` 或
  `:global(.el-*)` 覆盖。
- 需要新的通用控件表现时，优先为基础组件增加职责明确的属性或变体，不要新增只服务于
  单个页面的通用控件样式类。
- 当现有 `Ea*` 组件已经覆盖所需行为时，继续使用原生控件必须在这里记录例外原因。

当前允许的原生控件例外应保持在最小范围内：`CustomNumberInput` 负责允许中间输入状态的
数字草稿解析；`TimelineGrid` 的高频编辑器需要通过程序立即聚焦，因此继续使用原生控件；
文件、颜色和范围输入仍保留浏览器专用行为，当前基础组件暂不覆盖这些类型。

公共组件 API 和结构守卫测试是最终依据。本文件只说明设计系统的职责和使用边界，不作为
组件使用教程。
