# 游戏内提示条

提示条播放编辑器导出的轴，用干员、技能、倒计时和资源条辅助练习。它不读取游戏进程，也不修改项目、技能安排或模拟规则；可选的屏幕识别仅在开始监测后比较参考画面。实际操作与轴发生偏差时，需要手动暂停或校正。

## 浏览器预览

1. 在编辑器排好当前方案，检查原时间轴上的输入告警。
2. 点击工具栏的「游戏内提示」。入口等待当前模拟完成，将同一轮结果导出为独立快照，并打开提示窗口。浏览器拦截弹窗时，允许本站弹窗，或手动打开本站的 `/overlay`。
3. 按空格开始或暂停，按 `R` 回到起点并暂停；方向键跳转两秒，`Shift+←/→` 或控件中的 `−/+` 校正 0.25 秒。向左是让提示延后，向右是让提示提前。
4. 修改方案后，再点击编辑器的「游戏内提示」重新导出。暂停中的提示窗口会在一秒内读取新快照并回到起点；正在播放时保留原快照，暂停后再载入。

「开始前等待」默认 **2 秒**，可在设置中调整为 0–10 秒，设为 **0** 即禁用。每次从起点开始时，左侧计时先显示等待倒计时，结束后才播放轴；暂停再继续会保留剩余等待时间。点击「回到起点」或按 `R` 会回到起点并暂停，之后再次开始会重新等待完整时长。修改设置会在下次重新开始时生效。等待中使用时间校正会延长或缩短剩余等待，穿过等待结束的部分继续作用于轴时间。

轴内准备期仍使用原有负时间。等待结束后从最早准备动作开始，当前时间到零表示进入战斗；开始前等待不会替代或删减这些动作。下一操作同时显示干员和技能，同刻输入合并提示，相邻帧仍分别显示。资源条是模拟结果回放，不能代表游戏里的实际资源。

`S` 打开设置，`I` 切换技能图标与头像，`H` 切换控件显隐，`Esc` 关闭设置。设置可调整显示范围、宽度、缩放、不透明度及普攻和资源条。首次想看外观，可以打开 `/overlay?demo=1`；设置中的「读取已导出的轴」返回真实快照。

提示条使用自己的 IndexedDB 数据库和偏好键，不读写主程序的自动保存数据库。浏览器、Electron 和 OBS 浏览器源各有独立存储；即使 URL 相同，也不会自动共享轴。OBS 可用窗口捕获获取已打开的提示窗口。

## Windows 桌面悬浮窗

需要 Node.js 22.12 或更高版本。在仓库根目录安装 Web 依赖，桌面依赖单独安装：

```sh
npm ci
npm ci --prefix desktop
node desktop/launch.cjs
```

Windows 也可双击 `desktop/start-desktop.cmd`。它通过隐藏的 PowerShell 启动桌面版，不保留命令窗口；缺少 Node、依赖或启动失败时弹出错误提示。启动日志保存在 `%LOCALAPPDATA%\EndaxisOverlay\launcher\`，按工作树分目录，每次启动独立记录 `launcher`、`stdout` 和 `stderr` 日志。需要在终端查看实时输出时，仍可执行 `node desktop/launch.cjs`。

启动器会打开普通编辑器和透明置顶 HUD，两者使用同一个 Electron session。已有的 Edge/Chrome 项目需先导出 JSON，再从桌面编辑器导入；随后点击「游戏内提示」导出快照。

| 全局快捷键       | 操作                              |
| ---------------- | --------------------------------- |
| `Ctrl+Alt+Space` | 开始或暂停                        |
| `Ctrl+Alt+Home`  | 回到起点并暂停                    |
| `Ctrl+Alt+←/→`   | 提示延后或提前 0.25 秒            |
| `Ctrl+Alt+O`     | 切换鼠标穿透                      |
| `Ctrl+Alt+R`     | 重载 HUD 页面，按自动开始设置播放 |
| `Ctrl+Alt+Q`     | 退出桌面壳及其自有服务器          |

游戏中按 `F` 开战后，紧接着按 `Ctrl+Alt+Space` 启动等待；按怪物实际出现时间调整「开始前等待」。提示条不捕获或自动响应 `F`。`Ctrl+Alt+Home` 会回到起点并暂停，之后按 `Ctrl+Alt+Space` 重新等待完整时长；`Ctrl+Alt+←/→` 在等待中分别延长或缩短剩余时间。

播放和校正快捷键不聚焦 HUD，游戏可以保持前台。建议先检查快捷键，再开始练习。若解锁快捷键被占用，鼠标穿透会禁用；播放快捷键冲突会显示提示，启动 `stderr` 日志会列出具体键位，命令行启动时也可直接查看终端。HUD 设置或空状态中的「打开桌面编辑器」可重新打开编辑器。

窗口位置按显示器保存，大小随 HUD 实际内容调整。每个工作树拥有独立用户数据目录与固定本地端口；重复启动同一工作树会激活原编辑器。端口被占用时启动失败并报告原因，不会连接其它项目或工作树。不要删除占用端口的无关进程来处理此错误，应先核对启动来源。

只打开 HUD 可使用 `node desktop/launch.cjs --no-editor`。调试已明确选择的站点可使用 `--url=https://example.com/overlay`，此时不启动本地服务器；编辑器与 HUD 必须使用相同来源。远端站点必须已经包含本功能。

隔离验收可附加 `--user-data-dir=<独立目录>`，避免读取或覆盖日常桌面存档。它同时隔离窗口状态和浏览器存储；完成验收后关闭该实例即可。

游戏需使用无边框窗口或窗口模式。该功能是独立桌面窗口，不能保证覆盖独占全屏。是否置顶、游戏快捷键冲突及不同显示器缩放仍需在使用环境中检查。

## 屏幕倒计时自动启动（实验）

桌面版可用本地参考画面匹配启动轴，无需修改模拟规则或读取游戏内存。首次使用先让游戏倒计时可见，把提示条拖到游戏所在显示器，暂停提示条，在设置中点击「框选并保存参考」。框选会冻结该显示器的一帧，临时隐藏 HUD；拖出矩形后按 Enter 或确认，Esc 取消。尽量框住固定不变的冒号、边框或标识；功能只比较画面相似度，不读取或区分计时数值，变化数字可能导致漏检或误检。

保存后点击「开始监测」。当前已存在参考图案时，先等它消失再等待重新出现；否则直接等待出现。连续两帧确认后只触发一次，随即停止监测。自动触发从原轴起点开始并跳过「开始前等待」，确认阶段的经过时间会计入播放位置；原有负时间准备动作仍保留。每次重试需重新监测。手动开始、回到起点、重新载入 HUD 或退出会停止监测。

监测默认关闭。监测时请把 HUD、设置面板或其他遮挡移出选区。操作系统提供整屏截图，程序只在内存中裁剪选区进行匹配；只保存选区的小参考图、匹配模板和位置到当前桌面档案的 `countdown-trigger.json`，不保存全屏、不上传。清除参考会删除此配置。采样约每 200 毫秒一次且不并发，识别存在采样和画面获取延迟，可用原有 ±0.25 秒微调。更新桌面代码后须完全退出并重新启动桌面版，仅重载 HUD 不能更新主进程。

这是参考图案触发，尚未进行具体游戏的可靠性标定。动态背景、遮挡、HDR、UI 缩放或独占全屏可能导致漏检或误检；分辨率、显示器缩放或旋转变化时会停止监测并要求重新框选。先用窗口或无边框模式试跑，再用于实际操作。按 [Electron desktopCapturer](https://www.electronjs.org/docs/latest/api/desktop-capturer) 的接口，返回图像尺寸可能与请求不同；区域换算使用实际图像尺寸，不以主屏 DPI 推算其他屏幕。

## 开发与验证

功能位于 `src/ui/overlay/`。编辑器按钮仅等待已有的完整发布结果，导出期间项目变更则拒绝混合版本；`projectPlan.ts` 使用现有只读投影提取实际起止、费用和资源，`snapshot.ts` 保存纯展示数据。HUD 页面不导入项目加载器、模拟服务或编辑事务。

Web 接入仅涉及路由、工具栏按钮和导出回调；桌面代码和依赖在 `desktop/`。根依赖清单、项目格式、自动保存流程和模拟内核保持原样。图标和名称复用现有展示入口，未知费用不伪装成零，未知能量上限不宣布就绪。

```sh
npm run type-check
npx vitest run src/ui/overlay src/router/index.test.ts --maxWorkers=1
node --test desktop/desktop.test.cjs desktop/template-match.test.cjs desktop/countdown-trigger.test.cjs desktop/region-picker.test.cjs desktop/launcher.test.cjs
npm run build
```

交互回归位于 `tests/browser/overlay.spec.ts`，与现有浏览器测试共用配置：

```sh
npm run test:browser -- tests/browser/overlay.spec.ts --project=chromium
```

发布前实际检查：从编辑器导出而不是仅看示例；切换方案后重新导出；播放中重导出不打断；准备期、同刻动作和资源上限正确；中英文、窄窗口与最大缩放可读；游戏保持前台时能播放、暂停及校正；开启穿透后能解锁；退出释放自有服务器。单元测试或构建通过不能代替真实游戏与多显示器验收。

交互设计参考了 [cactbot 的时间轴说明](https://github.com/OverlayPlugin/cactbot/blob/main/docs/TimelineGuide.md)中的提前提示和时间校正，以及 [BigWigs 的倒计时入口](https://github.com/BigWigsMods/BigWigs/blob/master/Plugins/Pull.lua)与[提示条](https://github.com/BigWigsMods/BigWigs/blob/master/Plugins/Bars.lua)的操作辨认方式。这里采用手动控制，不引入游戏事件采集。
