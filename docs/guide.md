# 使用说明

本页说明时间轴的主要操作和结果含义。旧版存档通过转换器导入，不能直接按当前项目格式解释。

## 建立一个方案

选择各轨道的干员，再调整等级、技能等级、天赋、潜能和配装。从技能库放下技能后，时间轴会重新模拟，显示命中点、状态条和资源曲线。

技能块宽度表示这次操作的显示时长，不代表它产生的全部效果都已结束。持续伤害、Buff 和投射物可以延续到技能块之外。

输入告警表示该安排与模拟器已实现的游戏输入条件不符。时间轴仍按已放置操作执行并显示原因；程序错误和缺失定义则可能导致模拟失败，两者不是同一种问题。

## 让一串技能自动接续

选中同一轨道上相邻的至少两个技能，在右键菜单中设为连续组。组内只固定第一个技能的位置，后续技能跟随前段的实际显示结束时间，因此前段受时间膨胀影响时不必逐个挪动后段。

从技能库放下完整普攻或强化普攻序列时，会自动组成连续组；只放一段不会建组。连续组不能嵌套，涉及已有组时需要选全。组内接续仍会检查费用、冷却和技能输入条件，不会自动等到所有条件满足。

技能块连线用于表达排轴关系，可以连接两个技能块。它不等同于连续组，也不连接命中点或效果节点。

## 切人与闪避

切人标记决定主控干员，部分游戏条件会读取这项状态。闪避标签绑定具体干员，移动标签不会自动改变绑定对象。

普通闪避会影响当前技能和普攻接续。极限闪避表示作者声明本次闪避成功，可设置成功延迟；模拟器没有敌人主动攻击，不会自动判断敌人是否恰好在此时命中。

闪避不受体力不足阻止，界面不显示体力。是否获得极限闪避后续效果仍取决于实际执行的游戏条件。

## 选择随机模式

| 模式 | 命中伤害                 | 其他概率行为                                  |
| ---- | ------------------------ | --------------------------------------------- |
| 期望 | 使用该次命中的暴击期望值 | 按确定的频率序列决定是否触发，不产生半个 Buff |
| 随机 | 使用当前种子抽出的结果   | 使用种子和对应随机流取样                      |

可以重掷全局种子或为技能块设置单独种子，也可以覆盖某次命中的暴击结果。固定种子固定的是相应随机流；若执行路径改变，实际执行的行为也可能改变。

命中详情保留暴击率和本次暴击结果。打开详情或总分析不会重新抽样。期望模式存在会改变后续状态的离散选择，因此整轴显示的期望总伤不是对所有可能战斗路径求出的严格数学期望。

## 查看状态和伤害

同一对象上、相同 Buff ID 且持续时间重叠的状态会合并展示，开始和层数变化处显示图标与层数；有时间空隙的状态不合并。点击后可切换查看具体实例。

物理异常与破防共用一行。击飞、倒地、猛击、碎甲是物理异常，破防是相关状态。隐藏状态条不应丢掉它造成的伤害；命中详情可以继续查看来源。

紧凑布局把四条干员轨道限制在可用高度内；松散布局为状态展开更多空间。只在全局时间膨胀区间显示特殊高光，实体局部变速仍影响模拟。

总伤害分析与对象来源图回答不同问题：来源图解释效果怎样产生；贡献分析只分配已支持的直接加成，未分解部分计入攻击者。它不是完整的团队因果贡献评估。

## 保存、导入与导出

项目自动保存在当前浏览器中。浏览器数据不等于备份，换设备或清除站点数据前请导出项目。

导出面板可导出当前方案或全部方案的 JSON、数据码，以及当前方案图片。PNG 图片可以携带项目数据，再从项目加载入口恢复；普通 PNG 没有这种数据时不能作为项目打开。

方案复制会生成新的方案身份，内部技能和标记保留引用关系。继承方案保存独立的完整输入和继承边界，来源方案之后的修改不会自动传入。

导入旧轴时，网页默认选择“保留原时间”，也可选择“智能修复时间”。两种模式都会转换身份和推断必要的主控切换；智能修复还会调整技能衔接，可能改变 Buff 覆盖。请阅读转换问题汇总，原始文件不会被修改。

## 模拟范围与结果解读

- 当前模型只有一个不主动攻击的敌人，忽略移动、空间碰撞和投射物飞行路径。
- 技力属于全队，终结技能量属于各干员；结果按当前生成的游戏数据计算。
- 旧版时间轴通常能反映技能先后顺序，但绝对时间精度可能不同。转换后的告警不直接证明作者排错。
- 新旧模拟结果的差异用于定位问题，游戏行为以同版本原生证据为准。比较总伤前，应统一配装、随机模式和模拟截止时间。
- 新版本数据或运行时修复可能改变结果。导入成功、某次模拟成功，都不表示所有游戏机制已经支持。
