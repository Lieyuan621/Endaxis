# 桌面应用

桌面应用复用网页编辑器、游戏数据和模拟器，通过 Electron 提供窗口及操作系统能力。提示条是桌面应用的一项功能，不进入网页构建。

## 入口与依赖

`src/main.ts` 装配网页入口，`desktop/renderer/editor/` 装配桌面编辑器。两者使用共享的启动流程、编辑器路由和项目恢复逻辑。桌面编辑器通过工具栏插槽增加功能按钮，读取当前项目的只读快照和已发布模拟结果，不持有另一个模拟器。

依赖方向为 `desktop → src`。共享编辑器不导入桌面代码，也不读取 Electron 注入的全局对象。桌面专用界面、原生桥接和功能文案均放在 `desktop/`；`desktop/i18n/locales/` 使用 JSON 语言资源。网页产物不包含桌面路由、文案或延迟加载模块。

| 位置                                 | 职责                                             |
| ------------------------------------ | ------------------------------------------------ |
| `desktop/app/`                       | 应用启动、编辑器窗口、用户数据位置和本地资源协议 |
| `desktop/renderer/editor/`           | 复用共享编辑器并装配桌面功能入口                 |
| `desktop/features/overlay/main/`     | 提示条会话、窗口、快捷键和屏幕捕获               |
| `desktop/features/overlay/preload/`  | 各窗口明确限定的原生接口                         |
| `desktop/features/overlay/renderer/` | 提示条快照投影、播放器和独立设置界面             |
| `desktop/i18n/locales/`              | 桌面中文、英文文案                               |
| `desktop/build/`                     | 便携版打包配置                                   |

## 应用与功能生命周期

应用启动时创建编辑器。打开提示条时创建一个提示条会话，重复打开复用当前会话。会话拥有提示条窗口、设置窗口、框选窗口、屏幕识别、专用快捷键和监听。

设置是独立的非模态窗口，同一会话最多一个。关闭设置不会停止播放；关闭提示条则结束整个会话，销毁设置与框选窗口，停止识别并注销专用快捷键。已经发出的异步截图必须失效，不得影响随后创建的会话。再次打开提示条读取最新快照及持久化偏好，不恢复已关闭会话的播放进度。

关闭编辑器时，仍存在的提示条可以继续使用。编辑器与提示条均关闭后应用退出，设置窗口不能独自维持进程。

## 快照与设置

导出入口等待共享编辑器的完整模拟结果，核对项目版本与活动方案，然后提取提示所需的动作、时间、费用和资源曲线。提示条读取独立 IndexedDB 快照，不修改项目或自动保存数据；播放中收到新导出时，暂停后才载入。

提示条是偏好的唯一写入方。独立设置窗口发送字段修改或明确的操作命令，由当前会话转交提示条处理，再向设置窗口发布完整状态。设置窗口不直接修改另一份偏好，也不绕过播放器直接启动识别。原生接口按发送窗口校验，只接受对应窗口需要的能力。

自动开播的识别与计时语义见[使用说明](../overlay-user-guide.md)。它仍是实验功能，不提供持续实战同步。

## 便携存储与本地来源

Windows ZIP 包包含 Electron 与预构建界面。生产环境使用固定的标准安全来源 `app://endaxis/`，由主进程将页面和静态资源映射到包内文件，不启动开发服务器。资源请求限制在构建目录内。

用户数据位于 EXE 同级的 `data/`，Chromium 配置与 IndexedDB 位于 `data/profile/`。移动整个目录后来源和数据库身份保持不变；更新程序时保留 `data/`。目录不可写时报告错误，不静默改用其它保存位置。发布包不包含用户数据。

开发启动使用独立开发配置和存储，不能因开发路径变化影响便携版数据。原开发版的 HTTP 存储与固定应用来源不同，首次转用便携版通过已有 JSON 导入导出转移项目和预设。

## 验证

构建与打包命令见[使用与开发说明](../overlay-user-guide.md)。验证应覆盖网页不含桌面模块、共享编辑器事件转发、快照发布，以及原生窗口关闭重开与异步清理。

实际便携程序还需检查独立设置的双向状态同步、保存后移动目录、更新保留数据，以及中文和空格路径。窗口 mock 测试不能代替真实 Electron 验收；普通桌面验收也不能证明特定游戏中的全局快捷键、穿透和实验性识别可靠。
