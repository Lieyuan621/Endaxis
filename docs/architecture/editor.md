# 编辑器与项目

编辑器负责保存用户安排，并把一次操作作为一次可撤销修改提交。它不根据预期伤害偷偷替换技能，也不把模拟得到的宽度写回游戏定义。

## 模板、方案与实例

内置定义只读，项目自定义定义保存在项目库中。轨道引用定义并保存自己的养成和配装；多个轨道可以引用同一模板，但不能共享可变战斗状态。

整份方案复制时，只生成新的方案 ID。技能、轨道、标记和连线在方案内查找，副本深拷贝后可保留内部 ID 及其引用。向同一方案粘贴内容时则必须分配新 ID 并改写引用，避免冲突。

项目格式以 [schema.ts](../../src/core/project/schema.ts) 为准。定义编辑修改项目模板，技能块覆盖只影响该次释放；两者可以共用表单，但不能隐式双向同步。

## 编辑事务和输入归属

[scenarioEditorSession.ts](../../src/application/editor/scenarioEditorSession.ts) 等应用入口组织文档修改和历史。一次完成的操作对应一次撤销；浏览、选择和展开面板不创建修改记录。取消、失焦或异步失败不能留下半次编辑。

快捷键按逻辑输入区域路由。弹窗阻隔背景命令，关闭后恢复父区域；Teleport 改变 DOM 位置，不改变输入归属。文本框优先保留原生文本编辑行为。

手势会话必须有明确的所有者和身份。旧回调不能结束后来启动的手势；Escape、指针取消、失焦与卸载都要有取消路径。拖动预览不抢指针，菜单、工具栏和快捷键应调用同一编辑命令。

## 连续组

技能块宽度不代表所有效果已经结束。普攻按当前连段的下一段接续边界显示；战技、连携、
终结技统一按当前普攻操作可接续的边界显示，允许强化普攻替换，不固定为 A1。战技等
专用的提前接续窗口仍参与释放判定，但不缩短这些块的基准宽度。宽度不检查费用与冷却，
不依赖未来放置的技能；没有普攻路由时由技能实际结束兜底。模拟边界换算为下一输入帧，
生成宽度只供尚无实际结果时预览。若在边界前被后续技能中断，显示裁到实际中断位置，
不能再用预览宽度把它二次缩短。

原生 `MarkCanInterrupt` 必须保留为技能运行时动作，执行后与保护时间到期一起参与
`canInterrupt` 判定，并影响普攻接续块尾。标记属于执行动作的技能施放，进入切面，
每次重新施放清除；不能把它当纯输入表现过滤，也不能用干员显示配置替代缺失的动作。
洛茜战技的普通分支在内部第 49 帧执行该标记；分支跳转和时间膨胀后的块尾以实际模拟为准。

干员技能生成配置可用 `timelineBlockFollowUpSkillId` 指定技能块的接续参照技能，原样进入
技能定义。配置替代默认的接续目标，适用于各类技能，并非“手动结束”标记。参照技能
必须是同干员的其他可路由技能，且存在原生接续窗口；块尾取它实际可接续的时刻，技能
实际结束仍作兜底。只影响显示，不执行参照技能，也不改变持续伤害与 Buff 的寿命。
预览帧由接续数据推导，不手填帧数。梨诺以结束演奏操作为参照，其他技能也可配置普通
后续技能；未配置时沿用上述默认规则。

连续组通过技能的放置关系表达：组首保存 `startFrame`，后段用 `afterCastId` 引用前段，二者互斥。引用必须同轨、无环，每个成员最多一个后继，不另存一份成员表。

输入排程器根据前段实际显示边界安排下一帧输入。组首移动时整组跟随；时间膨胀改变前段长度时，后段在同次模拟中顺延。它不是反复修改存档并重算的循环。

禁用成员不占接续时间；全组禁用不产生输入。零宽的成功操作至少占一个输入帧。成功的同轨新操作接管输入后，旧组尚未执行的成员停止；失败操作不接管。停止及未执行状态由结果投影展示，不能伪造启动回执。

从技能库放下完整普攻序列时自动建立连续组。数据定义中的“技能组”只组织技能库选项，与用户连续组不是同一种结构。

## 方案继承

继承方案保存完整输入、构筑和配置，并记录最早允许新输入的继承帧与来源方案 ID。来源只用于导航；来源方案被修改或删除，不改变继承方案。

继承边界之前的历史由编辑约束冻结，模拟仍使用当前定义重跑。项目不保存运行时切面，不依赖旧引擎，不维护方案之间的运行依赖图。切面缓存只用于加速，可失效并重建。

复制、导入、导出和重置都要保留各自明确的语义。单独导出继承方案应保留边界；重置时是否保留继承关系由用户选择的重置范围决定。

## 结果发布与拖动

模拟服务只发布一轮完整结果。等待下一轮时保留已发布的状态、曲线和提示，不把计算中间状态逐块送到界面。

频繁拖动时，新请求可以替换尚未开始的请求，不能持续打断已经开始的计算。结果必须绑定对应的输入版本；旧结果不能覆盖新的项目或方案。短计算路径需要保持技能块和投影同步，后台长计算则避免阻塞手势。

[AdaptiveTimelineSimulationService](../../src/application/simulation/adaptiveTimelineSimulationService.ts) 在普通编辑时使用 Worker。拖动开始时，若最近一次完整、非缓存模拟不超过 50 ms（20 帧/秒的预算），整次拖动使用主线程上的同一套模拟器，让技能块和完整投影一起更新；否则继续使用 Worker。新的完整模拟耗时会替换旧记录，首次加载的慢模拟不会继续影响后续判断；缓存命中不更新记录。后端在本次手势内保持一致，拖动结束后恢复 Worker。50 ms 是选择后端的预算，不是限制刷新频率的定时器；性能面板也使用同一预算。

拖动不额外等待定时器：空闲时立即开始计算，已有计算进行时只保留最新待算位置，并在上一轮结束后立即接着计算。主线程与 Worker 共用这套调度规则。

修改这一机制应同时测短轴与长轴。只测 Worker 吞吐或固定延迟，不能证明实际拖动跟手；模拟耗时和页面绘制耗时要分开测量。

## 定义编辑器

技能块详情可以打开技能的完整动作图，主图与宏分别切换。草稿使用正式 `SkillDefinition`，不维护另一套画布程序格式。资源、分支去重、宏和执行规则见[动作图](action-graphs.md)。

### 只读、草稿与保存

从库中读取的图只能查看、选择、平移和缩放。参数修改、节点移动、重排、接线、删除和时间编辑都必须先选择“自定义”，深复制原定义后才能执行。

源定义和历史快照递归冻结，自定义副本不共享源定义的可变嵌套对象。修改命令检查自定义状态，不能仅靠按钮禁用保护。保存再次复制定义和布局，并检查打开后原定义是否发生变化；取消不提交任何草稿。

保存作为一次场景事务，只覆盖选中的技能块。项目模板、Buff 和实体的独立编辑入口不由技能覆盖隐式代替；扩展事项见[待办](../TODO.md)。

### 时间线与布局

施放时间线显示为画布入口节点，底部时间编辑区操作同一份调度数据。每条调度独占一行和一个出口；同一动作被安排两次，仍是两次调用。时间线节点完整显示所有出口，不分页；通过画布平移和缩放浏览。

横轴是相对施放开始的局部帧。拖动调度整体移动时间，拖动端点改变区间，也可精确输入。没有结束帧的点调度与起止相同的区间分别保留。区间负责启动、推进和结束动作，不表示动作链每帧重放，也不让 `next` 等待区间结束。

行序决定同次推进中各调度的处理顺序，包括已启动项与新到期项。开始时间与行序分别编辑，不能为排版方便自动换序。复制调度只复制调用和时间，删除调度只移除该调用，不复制或删除目标动作。事件响应由正式监听动作表达，不另造延时事件轨道。

Dagre 根据执行和数据依赖安排层级，同层按最早关联调度排序。共享节点只显示一次，排序约束只影响坐标。超高时间线的可见性按整个节点边界判断，不能只检查节点原点。

技能图使用整屏工作区；底部时间编辑区可收起或调整高度。选择节点或调度时突出相关连线，其他连线淡化。错误和手势状态不推开画布。

### 节点、引脚与检查器

交互借鉴蓝图编辑器，节点种类和执行语义仍由正式契约决定。节点标题统一为名称和实例 ID，最多两行；时间线和读取变量采用专用样式，读取变量使用紧凑节点。数值运算突出居中的运算符，不为明显的输入添加 A、B 等标签。

执行出口只通过连线修改，检查器不提供目标 ID 输入框。分支既有选择出口，也有同步“继续”出口；结束时间线的节点没有继续出口。变量读取和纯运算没有执行引脚。

检查器使用统一字段布局。输入方式优先由类型描述确定；布尔、枚举、数值和资源选择不应一律退化成文本。解释用途的简短帮助放在字段名旁的小图标中，不铺在输入框下方；名称已清楚表达含义的字段不重复解释。节点说明放在检查器，不添加到画布标题或引脚旁。

| 对象   | 交互规则                                                                                       |
| ------ | ---------------------------------------------------------------------------------------------- |
| 画布   | 空白处左键拖动平移，也支持右键或中键拖动；滚轮围绕鼠标缩放，单击空白取消选择；右键单击打开菜单 |
| 节点   | 左键选择并拖动，F 或 Home 定位选中对象，Delete 删除；双击宏调用进入宏图                        |
| 引脚   | 支持正向和反向拖线，松手才提交；命中区限定为图形周围 16×16 图内像素，标签不接收接线            |
| 连线   | 悬停强调，单击选择；Alt 单击断开，右键菜单提供断开和定位                                       |
| 断线   | Alt 单击输出引脚断开该出口，Alt 单击输入引脚断开全部输入；一次操作只记一次历史                 |
| 检查器 | 普通输入在 Enter 或失焦时提交，选择框立即提交；非法输入保留并显示错误，Escape 放弃未提交输入   |

接线成功前保留原连接。拖到空白、Escape、失焦或指针取消不删除原线；节点拖动取消后恢复原位。所有修改由相同编辑命令完成并整体校验，菜单与快捷键不另写修改路径。

新建和删除节点从画布菜单操作。可创建候选由字段元数据和正式校验确定，菜单分类只负责组织候选；需要变量、宏或资源身份的节点不能用虚构默认值创建。生成说明见[节点描述工具](../../tools/editor/README.md)。

### 变量与数据连接

变量清单按调用环境和局部作用域分组，宏参数单列只读。清单展示初值及读写引用，并可定位节点。拖到空白处选择读取或设置，Ctrl 直接读取、Alt 设置；拖到数值输入可以创建读取并接线。修改读取键不等于重命名变量。

作用域分析沿执行连接传播，局部主体与外部续接分别处理。共享数据节点可能被不同上下文调用，不能给它指定唯一静态变量归属。外部上下文可能提供静态清单中未出现的变量，来源不明时提示而非直接判非法；已知跨越不允许的局部作用域则拒绝接线。

数据节点存入所属图的 `dataNodes`，不是临时显示节点。数值和布尔分别着色，常量可以直接编辑；所有、任一条件保留顺序与短路。求值与副作用规则统一见[动作图](action-graphs.md#数据连接与变量作用域)，UI 不自行缓存求值结果。

### 排版与撤销

技能块的 `customDefinition` 保存逻辑，`presentation.graph` 保存主图与各宏的节点坐标；数据节点坐标记录在 `dataPositions`。坐标采用图内单位，不受缩放或窗口大小影响。调度出口位置由行序决定，不另存坐标。

只有自定义图保存布局。库图每次打开按当前算法重新排列，不读写全局布局缓存。自定义图恢复已有坐标，只为缺失节点补位置；损坏坐标可以忽略，不阻止模拟。

逻辑和排版共用最多 30 步不可变历史。拖动松手、自动布局、字段修改和接线各形成完整一次操作；Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 或 Ctrl/Cmd+Y 重做。选择、视口与面板尺寸不进入历史或存档，关闭后不保存撤销栈。

只改排版不触发模拟，也不使正在运行的结果失效。技能逻辑、种子和禁用状态的修改仍需重新模拟。

### 代码入口与验证

- `src/application/editor/actionGraphEditing.ts`：图引用、节点和调度修改。
- `src/application/editor/immutableGraphDocument.ts`：只读保护、草稿与历史。
- `src/application/editor/graphBlackboard.ts`：变量清单和作用域分析。
- `src/ui/action-graph/`：画布、时间编辑区、检查器和菜单。

验证应覆盖只读对象不被修改、取消不留草稿、撤销重做恢复逻辑与布局、保存重开保留引用，以及共享数据节点在不同调用时分别求值。实际检查节点拖动、接线命中区、超高时间线和错误布局；类型通过不能代替浏览器验收。
