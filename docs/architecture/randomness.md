# 概率事件与随机模式

本页说明当前模拟怎样处理会改变战斗结果的随机事件。这里的“随机”不包括编辑器对象 ID、动画抖动、音效变体等表现用途，也不把空间位置或多目标选择伪装成数值概率。

## 当前支持的随机决策

正式运行时目前有两类随机流：

- 暴击流决定随机模式下一次允许暴击的伤害是否暴击。
- 概率流执行原生 `RandomUtil.Dice(probability)` 对应的 `probability` 条件。条件可以控制伤害、Buff、资源、治疗、能力实体或时间线跳转等任意后续动作。

两类流彼此独立。新增随机机制不能直接调用 `Math.random()`，而应先确认原生语义，再接入明确的样本端口和可恢复状态。

原生数据还包含随机空间点、目标洗牌和随机黑板写入。当前单敌人零空间模型只保留已经证明不依赖坐标的目标数量与回调次数；纯表现随机在生成阶段删除。无法证明不影响战斗的随机写入、目标选择或空间效果必须停止生成或预检失败。

## 两种模拟模式

场景保存 `expected` 或 `sampled` 模式；旧项目没有该字段时使用期望模式。

| 行为           | 期望模式                       | 随机模式                           |
| -------------- | ------------------------------ | ---------------------------------- |
| Hit 伤害       | 写入非暴击与暴击伤害的数学期望 | 按本次暴击结果写入非暴击或暴击伤害 |
| Hit 的暴击标记 | 除强制暴击外均为否             | 本次抽中或强制暴击时为是           |
| 暴击后续效果   | 允许暴击的 Hit 必定触发        | 仅本次实际暴击或强制暴击时触发     |
| 通用概率条件   | 使用固定频率的确定性序列判定   | 使用可复现伪随机流判定             |
| 全局种子       | 不影响默认固定频率序列         | 决定没有独立种子的随机结果         |
| 技能块独立种子 | 当前界面不在期望模式提供       | 接管该技能块及其派生行为的随机流   |

显式指定某个 Hit 强制暴击或强制不暴击时，两种模式都服从指定结果，不再抽取暴击样本。原生动作明确声明 `canCritical=false` 时，期望模式不会派发暴击后续事件；暴击率为零不能代替这项声明。

期望模式下，伤害回执中的 `isCritical` 只表示实际展示为暴击的结果。暴击后续事件使用独立的瞬时标记派发，不把“为确定性模拟而触发后效”伪装成一次实际暴击，也不把该标记写入项目存档。

## 离散概率的固定频率序列

Buff、资源、治疗、实体生成和时间线跳转会改变后面的战斗状态，不能像一次伤害那样简单乘以概率。期望模式因此仍选择一条完整、可执行的状态路径，但使用确定性的低差异序列代替伪随机数：

```text
0.5, 0.25, 0.75, 0.125, 0.625, 0.375, 0.875, ...
```

概率条件在 `sample <= probability` 时成立。零概率直接失败且不消费样本；百分之百概率成立。默认按来源身份拆分期望序列，避免一个干员或 Buff 的概率事件改变无关来源的触发频率。

这种做法让同一方案反复模拟得到相同状态，并让大量重复事件的触发比例接近定义概率。它不等于枚举全部分支后的严格数学期望：短时间轴中的一次 10% 事件可能完全不触发，而一次触发后会持续改变后续状态。因此“期望伤害”是每个 Hit 的数学期望，“期望模式总伤害”仍包含所选离散路径的影响。

## 随机模式、种子与恢复

随机模式使用场景的 32 位全局种子建立可复现伪随机流。技能块可以保存独立种子；种子只在输入实际提交时登记，不能提前读取整条时间轴的未来输入。

战斗切面保存随机配置、各流进度、期望序列位置和已经提交的技能块种子。回退或从切面继续后，同一输入与执行顺序必须得到相同结果。修改已经消费的技能块种子、用不同模式恢复切面或改变全局种子恢复已有随机状态都应明确失败。

随机结果依赖实际执行顺序。删除、增加或提前一个同流概率条件，可能改变后续结果；生成器不能随意保留会消费样本但已无战斗作用的条件。

## 当前数据中的用途

当前生成定义中的概率条件包括以下几类：

- 阿列什连携技钓起珍鳞，会改变伤害、技力和相关 Buff。
- 艾尔黛拉终结技分身概率生成影子，涉及能力实体与治疗链。
- 安塔尔、萤石和庄方宜的概率免伤及后续治疗或增益。当前产品没有敌人主动攻击，这些防御事件通常不可达，但定义仍按公共概率条件表达。
- 随机空间点或等价分支。在单敌人零空间模型中，它们可能只保留次数与稳定目标身份，不保留坐标。
- 已删除战斗消费者后的空分支或等价分支。这类条件不应仅为表现差异推进正式概率流。

生成定义只是原生程序的投影。某个文件里出现 `probability` 不代表该分支在当前场景一定可达，也不代表它必然影响伤害。

## 尚待确认

- **离散期望策略**：固定频率序列是否继续作为产品的长期方案；若要得到严格期望，需要对状态分支进行加权展开与合并，不能把概率 Buff 或资源直接乘成小数。
- **用户界面措辞**：总伤害面板需要持续明确区分“Hit 数值使用数学期望”和“离散状态选择一条确定性路径”，避免把整场结果描述成严格统计期望。
- **原生随机算法**：当前随机模式保证 Endaxis 内部可复现，尚未宣称复刻游戏进程的随机数算法、初始状态或各子系统共享顺序。
- **空概率分支**：审计生成定义中两边均为空或战斗结果相同的概率条件，确认哪些来自纯表现随机，并在转换器中证明后删除，避免挤占后续有效样本。
- **随机作用域**：继续核对原生概率是按全局、角色、Buff 实例、技能实例还是其他对象共享状态；当前来源序列和技能块种子是模拟策略，不冒充原生对象布局。
- **随机位置与目标**：如果以后加入多敌人或空间模拟，需要重新确认随机点、目标洗牌、命中上限和碰撞顺序，不能沿用当前零空间折叠结果。
- **新的概率消费者**：每次接入会影响伤害、Buff、资源、实体数量或时序的新概率分支，都要检查两种模式、切面恢复、技能块独立种子和执行顺序。
