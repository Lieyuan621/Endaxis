# 字段编辑的后续验收

字段控件的稳定职责见[编辑器架构](../architecture/editor.md)。本页只保留尚未完成的验收和扩展边界，不重复已实现阶段的开发记录。

## 浏览器交互

字段测试页已经具备相关场景，但编译、类型检查和测试发现不能替代实际浏览器执行。

- 验证资源选择、来源定位、无效引用提示和只读导航。
- 验证数值、条件、字符串引脚的连接、断开、取消、字面量替换及类型拒绝。
- 验证切换节点、主图、宏和文档后，旧表单事件不能写入新对象。
- 验证共享来源的删除保护、事务提交、撤销重做，以及保存后重新打开。
- 验证深层列表新增、删除和重排，检查未完成草稿不会破坏正式定义。

通过真实拖放、键盘及菜单操作确认结果，不能仅检查组件是否渲染或回调是否触发。

## 引用和作用域

静态资源引用应显示名称、身份、归属和失效原因。无法确定拥有者的动态上下文须明确显示未知，不猜测一个资源来填充候选。

只有正式契约允许的操作数槽可以接线。普通字符串、静态身份、声明和写入目标不能因为类型相似就升级成动态数据输入。变量读取必须保留所属资源、作用域、类型和遮蔽关系。

## 扩展边界

尚未覆盖的字段先补类型语义和共享分派，再选择控件，不逐个硬编码输入框。复杂结构使用专门的结构编辑或图导航，不以原始 JSON 作为正式交互后备。

字符串拼接、类型转换、字符串宏参数、对象与容器引脚，以及子资源创建向导，只在有明确使用需求时另行设计，不作为现有编辑功能的验收前置条件。

## 验收要求

- 编辑、编译、模拟、保存和重新打开使用同一正式数据契约。
- 非法输入在编辑边界提示，不以补零或隐式转换掩盖错误。
- 库资源只读；修改发生在独立自定义对象和事务中。
- 生成描述可重建，不提交个人样本、原始数据或一次性测量日志。
- 浏览器验证之外，按修改范围执行类型检查、生成检查和必要行为测试；不堆叠锁定源码写法的测试。
