# 投射物理论计算器

独立的手工配置辅助工具，不读取干员定义，不调用生成器或战斗运行时，不自动写入配置。

`calculateTrajectory` 接收世界坐标起点（可直接包含挂点近似）、初速度、恒定加速度、计算时长，以及可选的目标球和地面高度。单位为米、秒，Y 轴向上。输出轨迹采样、进入目标球的时间、落地时间及向上取整的 30 FPS 帧数。

直线与抛物线由同一公式计算。目标检测使用相邻采样之间的扫掠线段，曲线精度由 `stepSeconds` 决定，默认 1/300 秒。返回再次进入同一目标的记录，但这些几何接触不等于原生回调次数。没有接触就是空列表；计算到时限不代表原生投射物结束。

使用者据原生回调语义、命中限制与销毁规则审核计算结果，再手动填写 game-data-compiler 的时间表配置。工具不执行技能、不处理黑板、Buff、能力实体或生命周期。

工具支持恒速、恒加速度、给定控制点的贝塞尔路径和速度曲线积分；不实现追踪目标或原生随机控制点生成。此前依赖运行时计算的本地候选文件仅为迁移研究记录，不是该计算器的输出。

`parabolaFromApex` 根据水平距离、起终点高度、最高端点上方的顶点偏移和总时长，求出水平速度、初始竖直速度及重力。总时长是轨迹参数，启用速度倍率后不能直接当作回调时延；应继续计算缩放后的参数时间和首次接触位置。

`firstRayCapsuleEntry` 求射线首次进入竖直胶囊的距离，方向会归一化。`bottomY`、`topY` 是胶囊两端球心高度，半径不包含在这两个坐标中。球形投射物可通过扩大胶囊半径计算扫掠接触；无交点返回 `undefined`。结果必须再与投射物实际行程比较，不能把射线上的远处交点当成有限路径的命中。

`timeForTravelDistance` 独立计算速度曲线积分达到指定路程的时间。曲线横轴为秒数除以 `curveTimeScaleSeconds`；支持端点钳制的 Hermite 和带权贝塞尔曲线。加权段先反解时间坐标，再计算曲线值，不把贝塞尔参数直接当成时间；仅启用的权重参与计算，须显式提供 0～1 的数值。输入不包含原生资源、黑板、技能或生命周期对象，也不自动写配置。

`firstBezierSphereEntry` 接收四个世界坐标控制点和目标球，输出首次进入球体的曲线进度；默认按 8192 段寻找进入区间，再二分细化。它不生成随机控制点、不解释原生资源，也不判断回调是否触发。极小目标或切触可能被采样遗漏，需增加采样密度核对。当前配置使用的 3 米路径与 0.2 米球另以双倍采样复核。贝塞尔基准时长及曲线时间积分由调用者组合计算，不把弧长直接除以速度。

无权重曲线支持正负无穷切线形成的阶梯区段：保持左键值直至下一键，在跳变点分段积分，避免数值积分把突变抹平。原始数据保存为 JSON 时需保留非有限值的显式标记，不能接受自动转换的 `null`。阶梯切线用法可参照 [Unity 社区的一手 API 使用记录](https://discussions.unity.com/t/curve-key-tangent-mode-in-runtime-or-other-way-to-make-a-value-between-two-keys-constant/759201)；计算器测试以解析的分段常数积分独立验证，不把这条使用记录当作游戏时延实测。

加权模型依据 [Unity Keyframe.outWeight](https://docs.unity.cn/Documentation/ScriptReference/Keyframe-outWeight.html) 和 [inWeight](https://docs.unity3d.com/cn/6000.0/ScriptReference/Keyframe-inWeight.html)：未启用权重的方向取 1/3，零权重对应零长度控制柄。以归一化时间为横轴，控制点横坐标为出权重及 1−入权重，纵坐标按切线斜率计算。测试通过 `x(u)=u³` 的非线性时间参数和已知解析积分验证，防止误用 Hermite 或直接代入时间。该数学工具不是游戏运行时求值的逐位复刻。

`createCurveEvaluator` 可单独按输入坐标求曲线值，用于先计算距离相关的基础速度、弯曲幅度等参数；与时间积分共用同一套曲线求值，不依赖游戏黑板。
